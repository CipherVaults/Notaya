Notaya Roadmap

Ten upcoming versions, 1.6 to 2.5 (updated 2026-11-09, 12:00 UTC). 1.6 is about 85.5 size points, about 40 done (an estimate); every planned 1.6 lane is merged and checked on Ahmed's PC, none accepted; the usage-ledger forecast puts 1.6 at about 14 November and 2.5 at about 15 December (a forecast, not a promise). A version is a bundle of features: open a category to see its features, open a feature to see what it does.

Points (Waves tab) are a rough size score, about one developer working day each. They are not Claude or Codex quota or usage. The usage ledger tracks quota.

Sizes run XS, S, M, L, XL. Big means L or XL; Small means anything below that. "Needs your OK" marks a feature that changes security behaviour, adds a library, or changes the vault format, so it waits for a go from Ahmed before it is built.

Sizes are judgement, not measurements, and no dates are promised. Version 1.6 is in progress; everything after it is planned. This page is a plan to read and adjust, not a go to build.

Not placed yet: using all processor cores and in-memory indexes for huge databases (large-database plan items P11 and P12, only if measured need), synced blocks, button blocks, gallery covers from page content, an automatic backup helper, writing back to the old workspace, the whiteboard's later list (effect pens, handwriting to text, layers), and Notaya's own licence.
