## What changed and what stays responsible for each behaviour

`TableView.tsx` uses `useVirtualizer`, six overscan items each side and spacer `<tr>` elements between mounted ranges. The stream contains data rows, group/subgroup headers, New lines and group calculation lines. Only this range creates cell React elements and dnd registrations. The active cell/editor and drag source are retained by stable keys outside the range; a separate spacer fills every intervening gap. The Show more rows limit/button is removed. All rows returned by `query_view` are scrollable; Rust's 50,000-row cap and P1's notice are unchanged. Full result arrays, lightweight descriptor construction on result changes, selection sets and requery/JSON costs still scale with the returned result; only mounted screen work is bounded. P7 owns transport/windows later.
