## 6. Problems Encountered

**Errors / issues:**

- The newest `rand` and RustCrypto versions have different APIs from earlier releases.
- `reqwest`'s rustls feature pulls in aws-lc-rs, which may need extra build tools on Windows.
- TypeScript 6 rejects `baseUrl`.
- `Shell.tsx` spread a React `key` prop.
- `cargo remove rand` reported "not found".

**How they were handled:**

- Read the crate sources before writing code, and used `getrandom` directly.
- Used native-tls instead (A3).
- Removed `baseUrl`; `paths` works without it.
- Fixed the `key` prop before the type check.
- `rand` had already been dropped when `Cargo.toml` was rewritten, so the error had no effect.

**Unresolved problems:** none known. The runtime is unverified.
