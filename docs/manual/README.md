## How to update it for a release

1. Re-read the release notes (`docs/release-notes/`) and the changed screens; do not rely on memory.
2. Edit the HTML: change the edition line, add or fix the entries, move finished items out of "Coming soon" (the staging is in [`docs/plan/2026-11-07-version-plan.md`](../plan/2026-11-07-version-plan.md)), remove "known issues" that were fixed, and add a line to the change log in "About this edition".
3. Copy the file to the project's shared notes folder and republish the artifact to the same link.
4. Record it (Execution Summary, STATUS line) like any other work.

The in-app manual planned for 1.10 reuses this text.
