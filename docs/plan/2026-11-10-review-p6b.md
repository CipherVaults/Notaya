## Question for Claude — unproven, not a confirmed product finding

### Q1 — Question: focus may leave an inline table when its focused row disappears

- **Where:** `src/features/database/views/TableView.tsx:492`, `:507-521`, `:554-558`; `src/features/database/DatabaseView.tsx:134-141` and `:656`; inline route `src/features/notes/editor/DatabaseBlock.tsx:43`.
- **Exact proposed scenario:** in an inline/linked compact table, add a last row, name it and press Enter. P6 now focuses its active `<td>`. Undo the name, then undo the added row, then redo immediately without clicking/refocusing. Also try removal of a focused row by a filter/result change. When React removes the focused cell, browser focus can fall to the body. The passive cleanup only focuses the wrapper if it still contains `document.activeElement`; that condition may already be false. Compact DatabaseView explicitly skips the full-page document-level undo fallback. The next shortcut could therefore miss this database.
- **What a person might see:** focus leaves the inline grid and immediate redo/navigation fails until they click back. No secret or permission-boundary effect is alleged.
- **Proof limit:** source path inspected, **not reproduced**. TipTap/browser focus behavior must be observed before calling this a defect. The supplied successful added-row check is full-page and therefore exercises the fallback that compact mode lacks. The legacy inline test adds a row and navigates away/back; it does not undo/redo it without refocusing.
- **Smallest fix if confirmed:** remember whether the disappearing active cell owned focus before removal, then restore focus to the table wrapper after the DOM change, without taking focus from an unrelated control.
- **Test that resolves it:** extend the added-row scenario to an inline/linked view, assert `document.activeElement` after each history step, issue both redos without refocusing, and verify the same row ID/title. Repeat with an added group row and with a filter removing the active row. Record whether the shortcut reaches database history or the surrounding editor.
