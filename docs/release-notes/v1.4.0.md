# Notaya V1.4.0

This release adds **export and import of your pages**, a Windows **system tray**, more **colors**, a **page shelf and links between pages**, and a local **error log**. It also moves everything inside the app from the old name "Cipherleaf" to "Notaya". It has not been accepted yet.

Notaya is a notes app for Windows. Your notes are saved locally on your PC and nothing is sent anywhere.

## Downloads
| File | What it is |
|---|---|
| `Notaya-V1.4.0-setup.exe` | **Setup.** Installs Notaya for your Windows user (no administrator prompt). |
| `Notaya-V1.4.0-portable.zip` | **Portable.** Unzip anywhere and run `Notaya\Notaya.exe`. Your notes stay in a `data` folder next to it. |

Windows 10 or 11 with the WebView2 runtime is required.

## What changed since V1.3.0
- **Your notes are renamed and copied on the first start.** The notes file is now `vault.nota` (backups `vault-<time>.nota`), encrypted with Notaya's own labels. The first start copies your old `vault.clf` and re-encrypts it into the new file. **The old file is kept**, byte for byte, as `vault-before-notaya.clf`; backups from V1.3.0 and earlier stay and can still be restored. After the first start, use V1.4.0 only: a V1.3.0 Notaya must not be started at the same time (V1.4.0 tells you, and an older Notaya exits silently).
- **Export** pages, a section, a notebook, or several sections or notebooks at once, to **Markdown, HTML, PDF or Word**, as one file or as separate files in a ZIP. Exported files are **not encrypted**; the dialog says so.
- **Import** Markdown, HTML, plain text, Word, PDF (text only), ZIP files (including Notion exports) or a whole folder, several files at once. The result is **one new notebook**, saved all-or-nothing, with a Cancel button and a 15-minute limit. What carries over: [docs/plan/import-what-carries-over.md](../plan/import-what-carries-over.md).
- **Shelf** (a filled collapsible box), **Link to page** (a row that opens another page), and **links inside a sentence** to a page or to a heading.
- **System tray:** closing the window hides Notaya in the tray (on by default; a vault with a master password is locked first). Settings > Windows: **Start with Windows** and **Start minimized**.
- **Colors:** 18 matte highlight colors and 18 text colors, as two separate pickers.
- **Calculator history** keeps 500 calculations (was 200).
- **Error log:** `data\logs\notaya-log.txt` records crashes and errors (the place, the kind and a short call stack, never your note text, and nothing is sent anywhere). Settings > Error log shows its size and last entry and opens the folder. If Notaya was closed by a crash, the next start says so in the log.
- Two Settings lines and the uninstaller's "Delete the application data" box were removed.

## Known limits
- **PDF export uses standard fonts:** Arabic, Hebrew and Chinese/Japanese/Korean letters print as `?` and emoji are dropped (the app says how many). Word, Markdown and HTML keep every script. PDF import reads text only.
- **Round trip:** text colour is lost in Markdown and HTML; Word turns the yellow highlight into the app's orange and returns a code block as plain text; a notebook exported as one file imports as one page (use the ZIP to get sections and pages back).
- **Round-trip limits** (after the fixes made on 2026-11-03; colours, code blocks, task lists, captions, shelves and links between pages now come back): a link that points to a heading goes to the page; PDF files carry no links, and single Markdown files keep link text only; the order of notebooks, sections and pages in a ZIP comes back sorted by name, not in sidebar order; two names that differ only by capital letters come back as `Name (2)`; at most 100 notebooks per import; nested Word task lists come back flat; a Word code language keeps only letters, digits and `-`; colours from HTML style sheets are not read (only inline colours); a notebook exported as one file imports as one page (use the ZIP to get sections and pages back).
- After a crash of the app's web view the window can stay blank and nothing is logged.
- Tables wider than 64 columns are cut in exports; GIF and WebP pictures are left out of PDFs; a link to a deleted page shows "Page not found".
- Import was tested on files made by Notaya and a few hand-made samples, not on real Notion exports.
- Old and new Notaya cannot run at the same time, even on different data.
- The program's own license has not been chosen yet. Limits listed for V1.3.0 that this release does not change still apply.
