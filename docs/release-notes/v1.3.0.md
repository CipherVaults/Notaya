# Notaya V1.3.0

This release adds a **Windows setup** (installer). The portable ZIP is still there, so every release now has two downloads. It has not been accepted yet.

Notaya is a notes app for Windows. Your notes are saved locally on your PC and nothing is sent anywhere.

## Downloads
| File | What it is |
|---|---|
| `Notaya-V1.3.0-setup.exe` | **Setup.** Installs Notaya for your Windows user (no administrator prompt), with a Start menu shortcut and an optional desktop shortcut. |
| `Notaya-V1.3.0-portable.zip` | **Portable.** Unzip anywhere, a USB stick too, and run `Notaya\Notaya.exe`. Your notes stay in a `data` folder next to it. |

Both are the same app. Windows 10 or 11 with the WebView2 runtime is required. The setup downloads Microsoft's WebView2 only if your PC does not have it.

## What changed since V1.2.0
- **New: Windows setup.** Run it and follow the pages (Welcome, Install location, Finish). On the last page you can untick "Run Notaya" and "Create desktop shortcut".
- **Installed notes live in `%LOCALAPPDATA%\Notaya Notes\data`** (Settings > "Open data folder" opens it). The program itself is in `%LOCALAPPDATA%\Notaya`.
- **Uninstalling never deletes your notes or their backups.** The uninstaller tells you where they stay. Do not tick "Delete the application data" unless you want the browser data of the app removed; your notes are not in that place.
- **To update:** close Notaya and run the newer setup over the old one (keep "Uninstall before installing" on the "Already Installed" page). Your notes are not touched. The setup refuses to install an older version over a newer one.
- **Import from a portable copy.** The first time an installed Notaya starts with no notes, it offers "Start new notes" or "Import notes from a portable copy". Choose the portable Notaya folder: your notes and backups are **copied** (the portable folder is not changed). Close the portable Notaya first; an installed and a portable Notaya cannot run at the same time.
- **The portable ZIP now has a small `portable.txt` file** that tells Notaya to keep its notes in `data` next to the program. Keep it, and copy the whole folder when you move it. A lone `Notaya.exe` without `portable.txt` and without a `data` folder counts as an installed copy.
- No other behaviour changes. Existing V1.0 to V1.2.0 portable folders open unchanged.

## Checked, and not checked

## Known limits
- **"Uninstall Notaya" in the setup window:** if you run the setup over the same version and choose "Uninstall Notaya" on the "Already Installed" page, Notaya is removed, but the setup then carries on and installs it again. Your notes are not touched. To only remove Notaya, use Windows Settings > Apps instead.
- The setup's side picture on the first and last page is the standard installer picture, not a Notaya picture.
- After an uninstall an empty registry key `HKEY_CURRENT_USER\Software\Notaya` stays behind. It is harmless.
- No automatic updates: you download the new setup yourself.
- Contrast: white text on the coral buttons is about 3.6 to 1, and coral text on the cream background is about 3.5 to 1; this is below the 4.5 to 1 guideline for small text.
- "Match Windows" follows Windows into Black or White, not into the Sunrise looks.
- Names inside the program that do not show on screen still say Cipherleaf on purpose (the app identifier, the vault file format, the `CIPHERLEAF_HOME` setting), so existing notes keep working.
- The calculator history is saved in the vault and its backups until you press Clear. If an older Cipherleaf opens and saves the same vault, the history is dropped.
- The ribbon has not been tried with a screen reader or with the keyboard only.
- Still open from V1.1.0: a page with a content type this version does not know opens empty and could be overwritten; a link clicked in a page in the Trash can navigate the window away; parallel wrong-password attempts are all tried before the delay applies; an open vault (security off) does not lock when the drive is removed; stopping WebView2's startup traffic needs browser flags and is a security-behaviour choice.
- The program's own license has not been chosen yet.
