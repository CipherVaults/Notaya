# Notaya V1.5.0

This release adds **Arabic and Hebrew text that stays right-to-left**, **PDF export that prints Arabic, Hebrew, Chinese, Japanese and Korean letters**, and **full Notion-style databases** (with automations), all local. It also reads Notion exports much better. It has not been accepted yet.

Notaya is a notes app for Windows. Your notes are saved locally on your PC and nothing is sent anywhere.

## Downloads
| File | What it is |
|---|---|
| `Notaya-V1.5.0-setup.exe` | **Setup.** Installs Notaya for your Windows user (no administrator prompt). |
| `Notaya-V1.5.0-portable.zip` | **Portable.** Unzip anywhere and run `Notaya\Notaya.exe`. Your notes stay in a `data` folder next to it. |

Windows 10 or 11 with the WebView2 runtime is required.

## What changed since V1.4.0
- **Right-to-left per block:** Arabic and Hebrew text is right-aligned automatically, and a button sets a block to right-to-left or left-to-right by hand. The choice survives import, backup restore and export (HTML, Word, PDF).
- **PDF export** prints Arabic (joined letters) and Hebrew from fonts bundled with Notaya, and Chinese, Japanese and Korean from fonts Windows already has. Other scripts (for example Cyrillic) and emoji are still replaced; use Word to keep them.
- **Databases:** every property type (text, number, select, multi-select, status, date, checkbox, URL, email, phone, person, files, relation, rollup, formula, button, created/edited), seven views (table, board, list, gallery, calendar, timeline, chart), nested filters, sorts, groups, calculations, sub-items, templates, row pages, inline and linked views, and a chart dashboard. Rows can hold files (up to 50 MB each; they are stored encrypted in your notes).
- **Automations and the Button property:** when a row is added, a property changes or a date arrives, Notaya can set a property, add a row, show a message in Notaya or move a row to the trash. Everything stays inside Notaya (no network, no programs, no files). Chains stop after 3 steps, one run does at most 200 actions and 50 new rows.
- **CSV and Notion import:** a CSV file becomes a database (up to 50 MB, 100,000 rows, 100 columns). A Notion export becomes real databases: each row appears once with its page text, relations become real links between rows, and Status, Select and Number columns are recognised. A Notion **Markdown & CSV** export and a Notion **HTML** export of the same workspace can be imported **together** (as ZIP files, folders or loose files): each page is imported once, with the HTML formatting and the CSV data.
- **Database export** to CSV, Markdown, HTML, Word and PDF.
- **Reminders** from date properties appear as messages inside Notaya (no Windows notification).
- A safety backup is made before the first database is created in a vault. **After that, V1.4.0 or older cannot open that vault** (it reports it as damaged). Use V1.5.0 for that vault from then on.

## Known limits
- V1.4.0 and older cannot open a vault that has a database (see above).
- Notion exports do not mark person, formula and rollup columns, so they come in as text. Databases (tables) inside a page, comments and page history are not imported from Notion.
- PDF: other scripts (for example Cyrillic) and emoji are replaced; narrow database columns may wrap dates.
- Databases: no list of trashed rows (the undo message restores a row), no picture thumbnails in file cells, footers ignore the search box, one chart per view (no multi-chart dashboard), a Button does not use an "only if" filter, the table has no paste handler for several cells.
- Reminders are messages inside Notaya, not Windows notifications.
- After a crash of the app's web view the window can stay blank and nothing is logged.
- Old and new Notaya cannot run at the same time, even on different data.
- The program's own license has not been chosen yet. Limits listed for V1.4.0 that this release does not change still apply.
