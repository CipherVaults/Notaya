# Notaya V1.5.1

This is a fixes release for V1.5.0, with a few additions the owner asked for at the same time: **going back with Backspace or the mouse**, **undo and redo in databases**, **page icons and cover banners**, a new **Home page**, **Mermaid diagrams**, pictures you can **place anywhere on the page**, and import limits of **2 GB**.

Notaya is a notes app for Windows. Your notes are saved locally on your PC and nothing is sent anywhere.

## Downloads
| File | What it is |
|---|---|
| `Notaya-V1.5.1-setup.exe` | **Setup.** Installs Notaya for your Windows user (no administrator prompt). |
| `Notaya-V1.5.1-portable.zip` | **Portable.** Unzip anywhere and run `Notaya\Notaya.exe`. Your notes stay in a `data` folder next to it. |

Windows 10 or 11 with the WebView2 runtime is required.

## What changed since V1.5.0
- **Back and forward:** Backspace, Alt+Left or the mouse's back button goes back; Shift+Backspace, Alt+Right or the forward button goes forward. Buttons in the title bar do the same. It does not act while you type in a field or in a dialog, menu or database table.
- **Scroll bars** are always visible, at the bottom and the right, and a database table scrolls inside itself.
- **Undo and redo in databases:** Ctrl+Z and Ctrl+Shift+Z (or Ctrl+Y) for cell edits, titles, new rows, deleted rows and row order.
- **Tags and dates** in a table open on one click.
- **Automations:** "Add an action" no longer opens and closes by itself.
- **Charts are clickable:** hover shows "Click to view data"; a click lists the rows behind a bar, slice or point.
- **Dark looks:** dropdown lists are readable.
- **Hide all** on the sticky notes board (and in the tray menu) closes every sticky note window and keeps the notes.
- **Recent searches:** the search box remembers your last 5 searches (stored in your notes file, encrypted when security is on; X forgets one, "Clear recent searches" forgets all).
- **Pictures anywhere:** drag a picture to place it freely on the page, or to the left or right so text wraps around it; resize by percentage or by ratio (1:1, 4:3, 3:2, 16:9, 9:16).
- **Import limit 2 GB** for text, Word, PDF and CSV files and for ZIP files (4 GB unpacked). A picture or a file attached to a database row can be up to 900 MB, because Notaya stores each in one piece.
- **Page icons and covers:** pick an emoji (or a small picture) and a cover banner (gradient, colour or your own picture, which you can reposition) for any page. Icons show in the sidebar and in search.
- **Home page:** a banner, your favorites, recent pages and notebooks.
- **Mermaid diagrams:** insert a Diagram block (type `/` and "Diagram"), write Mermaid code and see the picture. Flowcharts, sequence, class, state, Gantt, pie, ER, mindmap and Git graphs. Everything is drawn on your PC. Imported `mermaid` code blocks become diagrams.

## Known limits
- The Notion "Hubs" main page that was reported missing could not be reproduced (not in the files available); send the export if it still happens.
- A very large Mermaid diagram can freeze the window for a moment; HTML export keeps a diagram as its code.
- Pictures placed freely stay in the text flow inside columns, lists and tables.
- Attaching a file of hundreds of MB to a database row is slow.
- V1.4.0 and older cannot open a vault that has a database (as in V1.5.0). The program's own license has not been chosen yet. Mermaid brings one package under the EPL-2.0 license (`elkjs`), listed in `THIRD-PARTY-NOTICES.md`.
- Limits listed for V1.5.0 that this release does not change still apply.
