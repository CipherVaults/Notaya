## 👥 Delegation and integration

Assign non-overlapping targets or an explicit integration owner before concurrent edits. Workers must return changed artifacts, evidence, assumptions, unresolved issues, and any authority/source conflict. A worker may not expand the task's permissions.

The integrating agent inspects the combined result, resolves conflicts, runs relevant integration checks, and updates the owning records before claiming completion. Independent worker passes do not by themselves establish a whole-system pass.

## 📚 Documentation changes

Use the project source map to identify which question changed and its owner. Read each affected document before editing. State its purpose, preserve a recoverable baseline when warranted, apply the smallest coherent change, inspect the diff, and read back the intended destination.

Use the project's full Session Summary template for substantial session memory and keep new entries newest-first unless the owner explicitly directs a different archive convention.
