# Headers and visual recipes

Apply the shared identity in SKILL.md, then choose the header by evidence type. These are tested starting points; adapt dimensions and text sizes to the current data and viewing surface. Simpler panels and larger text beat squeezed labels.

## Published comparisons

Use an unobtrusive upper-right source credit, with an authentic logo if available/useful/permitted. Suitable wording includes:
- "Independent evaluation · Artificial Analysis"
- "Vendor-reported · Anthropic"
- "Vendor-reported · OpenAI"

Identify evaluator and publisher separately when their roles differ. This is an independently prepared chart of cited results; do not imply the source organization authored or endorsed it. A very faint source-colored corner wash is optional. Keep the comparison palette stable across sources.

State benchmark/version, units, higher/lower-is-better and evidence date beneath the title. Preserve model/effort/fallback and relevant settings on rows. Label incompatible cohorts separately. Composite index points are not percentages; rounded ties or small gaps alone do not establish significance.

Starting recipe:
- DejaVu Sans regular/bold, or a readable available sans-serif.
- Width 2,200 px, content-driven height, about 64 px side margins.
- Title 46–52 px; row/model labels 30–32 px; settings/units 25–28 px; values about 30 px; notes 23–29 px.
- Blue #2368A0; orange #C96D24; text #1B2938; muted #526273; grid #E4E9EF.

## Personal local-AI tests

Header order:
1. Relevant software identification on the left, model-maker identification on the right; use authentic logos when available or plain text otherwise.
2. "PERSONAL LOCAL AI TEST · date" between them.
3. Prominent exact model + quantization.
4. Smaller relevant hardware/software/context strip, divider, then chart title.

The archived example identifies Unsloth as software and Meta as model maker, with "Llama 3.1 8B Instruct · Q4_K_M" and "RTX 5060 8 GB · Ryzen 5 5600X · 32 GB RAM · Windows · 8K context." These describe the 9 October 2026 example only; verify current inputs instead of using them as defaults. They imply no testing, verification or endorsement by Unsloth or Meta.

Keep sequence charts chronological. Orange can emphasize the final observation. Label first-to-last versus adjacent-step takeaways distinctly. Sequential replies are a personal record, not automatically a controlled comparison.

Starting recipe:
- DejaVu Sans; 12-inch-wide figure at 160 dpi (1,920 px), flexible height.
- Title 22 pt; model heading 18 pt; values about 17 pt; body 12–13 pt; notes about 10.5 pt.
- Blue #345BC5; orange #C46629; text #202B3B; muted #657185; grid #E5E9EF; unused capacity #EAF0F9.

## Quality versus cost/effort

Plot every requested observed setting in each compatible source cohort. Use color plus marker or line-style distinctions and legible effort labels (a numbered key can help). Supply exact score-cost pairs in a companion table. State logarithmic or focused axes and the price/publication dates. Missing cost or score is unavailable, not zero. Historical listed prices do not automatically represent current prices or the user's actual cost.

When useful, show adjacent quality gain and added cost. Connecting segments are visual guides, not forecasts, interpolation or fitted response curves. Do not divide Elo by cost as a ranking.

## Layout and languages

Keep logos compact and proportional, data marks plain, labels directly associated with values, and explanations brief. Use no rainbow palette or oversized branding. At phone width, split dense figures or add a simpler companion and accessible table. In Arabic, use proper shaping/RTL layout and inspect mixed-direction model names, units and numbers. Verify bilingual outputs use identical data.
