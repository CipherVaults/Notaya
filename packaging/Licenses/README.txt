Files in this folder are copied into the Licenses folder of the portable ZIP when it is built:
  WebView2-LICENSE.txt               Microsoft's license text for the WebView2 loader library linked into
                                     Notaya.exe (from Microsoft.Web.WebView2 1.0.3800.47 on NuGet).
  NotoSansArabic-OFL.txt             SIL Open Font License for the Noto Sans Arabic glyphs Notaya embeds in PDF exports.
  NotoSansHebrew-OFL.txt             SIL Open Font License for the Noto Sans Hebrew glyphs Notaya embeds in PDF exports.
The ZIP's Licenses folder also holds THIRD-PARTY-NOTICES.md (copy of the repository root file).
