Files in this folder are copied into the Licenses folder of the portable ZIP when it is built:
  WebView2-LICENSE.txt               Microsoft's license text for the WebView2 loader library linked into
                                     Cipherleaf.exe (from Microsoft.Web.WebView2 1.0.3800.47 on NuGet).
  KeePassXC-LIBRARIES-SOURCE.txt     where the source of the libraries inside KeePassXC is.
The ZIP's Licenses folder also holds THIRD-PARTY-NOTICES.md (copy of the repository root file) and, in
Licenses\KeePassXC\, KeePassXC's own license files and source archive (not kept in the repository).
