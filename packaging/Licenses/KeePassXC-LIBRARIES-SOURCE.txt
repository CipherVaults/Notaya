Source for the libraries inside the bundled KeePassXC 2.8.0
===========================================================

The KeePassXC folder next to Cipherleaf.exe is the unmodified official KeePassXC 2.8.0
Windows x64 portable build. The complete source of KeePassXC itself is in
Licenses\KeePassXC\keepassxc-2.8.0-src.tar.xz (also https://github.com/keepassxreboot/keepassxc/releases/tag/2.8.0).
That archive does NOT contain the source of the libraries below. Where a library's licence asks for
source, the source for the exact version is here:

Qt 6.11.2 (LGPL-3.0-only option; Qt's official build)
    https://download.qt.io/archive/qt/6.11/6.11.2/submodules/qtbase-everywhere-src-6.11.2.tar.xz
    https://download.qt.io/archive/qt/6.11/6.11.2/submodules/qtsvg-everywhere-src-6.11.2.tar.xz
    https://download.qt.io/archive/qt/6.11/6.11.2/submodules/qtimageformats-everywhere-src-6.11.2.tar.xz
    git tag v6.11.2 of https://github.com/qt/qtbase, qtsvg, qtimageformats, qttranslations
libqrencode 4.1.1 (LGPL-2.1-or-later)
    https://github.com/fukuchi/libqrencode, commit 715e29fd4cd71b6e452ae0f4e36d917b43122ce8
readline 5.0, readline-win32 port (GPL-2.0-or-later; used only by keepassxc-cli.exe)
    https://github.com/xiaozhuai/readline-win32, commit 0fa4001557c27157a51a9ca7f32a8c50bc97927a
Botan 3.12.0 (BSD-2-Clause)
    https://github.com/randombit/botan/archive/3.12.0.tar.gz
zlib 1.3.2 and minizip (Zlib)
    https://github.com/madler/zlib/archive/v1.3.2.tar.gz   (minizip is contrib/minizip)
Build recipes (patches) used for Botan, zlib, minizip, libqrencode and readline: the vcpkg ports at
    https://github.com/microsoft/vcpkg, baseline 1600ce2ba1b6b621bfc5a31a785c4963b817a1c7

The Microsoft files (vc_redist.x64.exe, d3dcompiler_47.dll, dxcompiler.dll, dxil.dll) are Microsoft's
redistributables under Microsoft's terms. opengl32sw.dll is Mesa 11.2.2.

This is a list of public links written by Cipherleaf's maintainer, not a statement from the KeePassXC team.
The linked source archives were not downloaded or hash-checked when it was written. Details and what is
unverified: THIRD-PARTY-NOTICES.md, section "Libraries inside the KeePassXC package".
